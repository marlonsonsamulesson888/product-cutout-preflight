# 检查记录模板

- 任务与版本：
- 原件 / 结果 / 最终输出：
- SKU、数量与视角对应：
- 处理方式（蒙版、裁切、调色、重采样、生成等）：
- 允许改动与保护内容：
- 源像素、测量范围、实际放置尺寸：
- 本单要求的分辨率与依据：
- 有效 PPI（横 / 纵）：
- 轮廓、细杆、叉齿、内部间隙、刻字：
- 金属反光与真实材质：
- 深浅灰及最终背景检查：
- 最终文件复查：
- 问题与证据位置：
- 已检查通过 / 需返修 / 待确认 / 未检查：
- 检查者、日期及实际使用工具：

## 尺寸计算
有效 PPI = 对应方向像素数 /（对应放置毫米数 / 25.4）。
例如 1200 像素覆盖 101.6 mm 时为 300 PPI。仅是算术示例，不规定所有订单必须 300 PPI。
像素与毫米必须描述同一范围；不要把主体像素和带大量透明边距的画布尺寸混用。两方向分别计算。插值或生成增加的像素须披露，不等于新增真实产品细节。
