# 产品抠图验收

这是经所有者确认公开发布的文字版流程技能；公开发布不等于已安装到使用者环境。

用于餐具及其他产品图片入包装前的质量检查：确认版本、检查轮廓/透明边缘、保护真实材质，核对放置尺寸及最终导出。请在支持 Skill 的环境中读取 SKILL.md，提供原图、处理图、用途及放置尺寸。

## 包含
- SKILL.md：执行流程及边界
- references/review-record.md：检查记录模板与有效 PPI 示例
- VALIDATION.md：验证范围、模拟情境及限制
- PROVENANCE.md：候选来源及公开前检查

## 不包含
不含抠图模型、自动检测脚本、第三方运行库或客户图片。不需要 Python/Pillow 即可阅读文字流程；实际视觉检查需要能够读取图片的工具或人工检查。此版不能替代本机原版本的自动指标检查，也不会自动安装到新会话。

不能保证零错误、判断实际印刷色彩或代签生产验收。没有看到实际文件的项目仍为未检查。
